# Working on kargui (for AI agents and contributors)

kargui is a light native GUI framework for Rust on Windows 10/11. This file is for agents and people
who change kargui itself. To write an app with kargui, read `docs/llms.txt` and `docs/guide/en/`.

## Rules

- When you change the public API, update in the same commit: its doc comment and runnable example,
  the guide pages that cover it (`docs/guide/ja` first, then the English translation in
  `docs/guide/en`), the widget pictures and `docs/llms.txt` if they change.
- Every public item needs a doc comment and a runnable example. `cargo run -p xtask -- coverage`
  fails otherwise.
- Doc comments are in English. The guide is written in Japanese and translated to English.
- A bug fix comes with a test that fails before the fix (`crates/kargui/src/test.rs` has the
  `Harness` tests; pixel-level checks compare "draw only what changed" with "draw everything").
- Keep compiler warnings at zero.
- Do not add dependencies without a reason written in the commit message (the dependency count is
  one of the measured axes).

## Checks to run before merging

```powershell
cargo test --workspace --exclude kargui-spike
cargo run -p xtask -- check
```

`check` runs: the widget doc check, the widget pictures (`shots --check`), the AI index
(`llms --check`), the guide freshness check (`guide-check`) and the doc/example coverage
(`coverage`). After reviewing a guide page whose covered API changed, or after updating a
translation, run `cargo run -p xtask -- guide-check --update`.

## Where things are

| Path | What |
|---|---|
| `crates/kargui/` | The framework |
| `examples/` | Task book, settings, reader, table |
| `docs/guide/` | The guide (ja is the source, en the translation) |
| `docs/llms.txt` | Index for AI, generated by `cargo run -p xtask -- llms` |
| `tools/` | Measuring, the input-method check (`ime-check.ps1`, run only while the author is away via `away-run.ps1`), the AI writability test (`ai-test/`) |
| `bench/` | Measured results |
