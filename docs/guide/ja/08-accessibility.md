# 読み上げとキーボード

kargui は、すべての部品を読み上げソフト（ナレーター、NVDA）に渡します。部品の種類から役割（ボタン、チェック、スライダーなど）が決まり、名前は部品の文字から取ります。

## 名前

文字を持たない部品（スライダー、文字の無いボタン）や、同じ文字が何個もある部品には、`.label(..)` で名前を付けます。

```rust
# let mut volume = 0.5_f32;
# kargui::test::example(|ui| {
ui.slider(&mut volume, 0.0..=1.0).label("音量");
ui.button("×").label("閉じる");
# });
```

名前の無い操作の部品があると、記録（`set_logger` で渡した先）に `a11y.unlabeled` が出ます。

## キーボード

- Tab と Shift+Tab で、操作できる部品を画面の順に移ります。スクロールや一覧の見えない所にある部品へ移ると、見えるようにスクロールします。
- Space と Enter で、焦点のある部品を押します。
- スライダーは ←→↑↓ と Home・End、選べる一覧は ↑↓ と Home・End で動きます。
- 焦点の枠は、キーボードで移った時だけ出ます。
- 焦点は、焦点を持てる部品を押した時に移ります。何も無い所や文字を押しても、焦点は前の部品に残ります（Windows の部品と同じです。入力欄なら続けて打てます）。

## 一覧

一覧の行は「何件中何件目」を持ちます。見えている行（と選んだ行）だけを読み上げの木に入れるので、1 万件の一覧でも重くなりません。
